# V16 검증 기록

검토 기준: V15 `e53ea4c9032fb763520fd3bd650a04b75ac5fbb4`. 검증일: 2026-11-06 (Asia/Seoul).

## 변경과 재현

1. **이미지 수집 계획**: URL·selector·frameSelector·requiredLabels·sourceId·참조 출처 URL을 바꾼 캡처가 다른 슬롯 수집 후 통과하던 경우를 재현했다. 수집 당시 슬롯 계획 식별값을 개별 이미지에 저장하고 검사한다. 본문 문장만 바뀌면 그대로 쓸 수 있는 이미지는 재사용한다.
2. **최신성**: 오늘 접속한 2024년 기사, 게시일 미상, 미래 게시·수정일, 오래된 조사 묶음, 무관한 최신 출처, 본문에서 쓰지 않는 현재 사실을 각각 검사한다. 최근 근거가 연결된 현재 사실과 과거 배경을 분리한다. 서울 자정 및 날짜만 있는 출처의 경계도 검사한다.
3. **작성 규칙**: 모든 후보의 길이·숫자·금지 기호, 후보 7개·서로 다른 유효 템플릿 ID 7개·태그 10개를 검사한다. 46~50자는 경고한다. 최종 제목의 기사 중복률 60% 경계 검사도 유지했다.
4. **일관된 기본값**: 공통 JSON에서 코드 기본값을 읽는다. 설정 파일 없이 1,500자 원고가 통과하고 13장 원고가 기본 제한에 걸리는 것을 검사했다. CLI의 이미지 수는 실제 만들어진 슬롯 수를 보고한다. 예전 13장 테스트는 사용자 명시 재정의로 한도를 늘린 경우다.
5. **교차 배치**: 이미지마다 일반 본문 한 문장을 넣는다. 미리보기와 편집 이벤트의 순서 및 이미지·본문 항목 개수 불일치를 검사한다. 사진 캡션은 만들지 않는다.

## 확인 범위

최종 명령 결과는 이 파일 하단에 기록한다. 브라우저 검사는 새 임시 브라우저와 로컬 테스트 페이지만 사용한다. 실제 네이버 로그인 계정의 임시저장 성공이나 원고 사실성·사진 의미 적합성을 뜻하지 않는다.

V15의 실제 네이버 계정 검증은 [당시 기록](validation.md)이며 V16 실계정 검증으로 간주하지 않는다. 원래 원격 저장소에는 push하지 않았다.
