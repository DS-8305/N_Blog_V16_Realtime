# 참고 코드

사용자가 지정한 다음 저장소의 고정 커밋을 읽고 필요한 기능을 이식했다. 참고 저장소 자체는 수정하지 않았다.

| 저장소 | 기준 커밋 | 이식·참고 범위 |
|---|---|---|
| [DS-8305/T_Blog_V05_realtime](https://github.com/DS-8305/T_Blog_V05_realtime) | `ce5c13ba85f6da1695bacc9e69fd431d24208e5b` | `image_collector/` 전체 Python 패키지, `src/cli/imageCollect.ts`의 결과 manifest 해석 |
| [DS-8305/N_Blog_V11_stock](https://github.com/DS-8305/N_Blog_V11_stock) | `628f0585c89911e6ee3950b7a3f2253e9d443058` | 캡처 준비·영역 캡처, 작업·브라우저 잠금, 소유 탭, 에디터 선택자·포커스·텍스트·사진·사진 설명, 저장 후 재조회 방식 |

Python 패키지는 원래 코드와 같은 검색기 구조를 유지하며 이 CLI에서 단일 이미지 슬롯별로 호출한다. 네이버·구글 검색 결과의 HTML 변경이나 차단은 별도 운영 진단이 필요하다.

네이버 코어는 `src/domain/types.ts`와 `src/state/files.ts`의 공통 계약으로 연결했다. 주식 전용 금융 검증·고정 5개 화면·다단계 승인, 티스토리 광고·그리드·발행 방식은 이식하지 않았다. 저장 기계와 일반 이슈 원고·이미지 슬롯 처리는 이 프로젝트에서 작성했다.

참고 레포의 README와 오래된 템플릿은 현재 코드와 차이가 있어 이 프로젝트의 운영 계약에는 그대로 적용하지 않았다. 현재 기준은 본문 1,000~1,200자, 각 소제목 이미지 3장, 기본 총 12장, CDP 9225, 네이버 임시저장이다.
