## 별도 코드 리뷰와 보강

별도 문맥의 리뷰어가 `38e1fc8..5678e70`의 코드를 읽고 중요 지적 4개를 제시했다. 각각 실패하는 재현 검사를 확인한 뒤 수정했다.

1. 화면에 아직 나타나지 않은 업로드도 재전송될 수 있었음: 미확인 이미지 입력은 이전 화면과 같더라도 재전송하지 않는다.
2. 체크포인트 저장 직후 시도 기록을 지우기 전 중단되면 재개가 막혔음: 이미 확인한 동일 인덱스를 검증한 뒤 시도 기록만 정리한다.
3. 저장 목록이 닫히자마자 기존 에디터를 성공으로 볼 수 있었음: 먼저 재로드한 빈 에디터를 확인한 후 유일한 저장 글을 선택하고 내용 도착을 기다린다. 지연된 불일치 원고 검사로 재현·수정했다.
4. 텍스트와 이미지 목록만으로 사진 설명의 소유 관계·배치를 확인할 수 없었음: 인용·본문·이미지·각 이미지 설명을 포함한 순서 있는 구조를 비교한다. 본문 내부 띄어쓰기를 전부 삭제하던 비교도 좁혔다.

강화한 문단 비교가 로컬 에디터 모형의 Enter 처리 오류를 드러냈다. 활성 문단을 정확히 선택하도록 테스트 모형을 수정했으며 실제 비교 조건을 완화하지 않았다. 수정 후 일반 41개, Chrome 3개 검사를 통과했다.

리뷰어가 실제 계정 없이 판단하지 않은 생산 네이버 DOM·원고 사실성·이미지 의미상 중복·사용 조건은 아래 인수 범위와 Codex의 내용 검토로 남긴다. 적대적인 동시 파일 교체까지 방어하는 다중 사용자 보안 시스템은 이 단일 사용자 로컬 도구의 범위에 포함하지 않았다.
